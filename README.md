# Karaokay — 音程トレーニング

運動性音痴（音の高さは聴き分けられるのに、声で再現できない）を改善するための練習ソフトです。
**自分の声の高さをリアルタイムに目で見る**ことで、「どれくらい声をずらせば合うか」の感覚をつかむのが狙いです。

## 起動方法

1. `start.bat` をダブルクリック（Node.js が必要です）
2. ブラウザ（Chrome / Edge 推奨）で `http://localhost:8765/` が開きます
3. 右上の「🎙 マイクON」を押して、マイクの使用を許可します

※ `index.html` を直接ダブルクリックしても動きますが、マイクの許可を毎回聞かれることがあります。
※ **ヘッドホンの使用を強くおすすめします。** スピーカーの音をマイクが拾うと正しく判定できません。

## 🎤 音源トレーニング

ボーカル抽出した音源（mp3 / wav / m4a など）を読み込み、お手本の音程カーブと自分の声を重ねて比べます。

- **音源を開く / ドロップ** → 自動でお手本の音程を解析し、青い帯で表示します
- **● 歌って録音** → 再生と同時に録音。終わると採点し、自分の声の線を色分けして表示します
  - 緑：ずれ±50¢以内 ／ 黄：±100¢以内 ／ 赤：それ以上（100¢＝半音1つ）
- **下の全体バーをドラッグ** → 練習区間を指定（1フレーズずつの反復練習に）
- **聴く：原曲だけ／原曲＋自分／自分だけ**、「左右に分ける」で聴き比べ
- **ガイド音** → お手本の音程を電子音で鳴らします（ボーカルが聴き取りにくいとき）
- **録音タイミング補正 / 自動で合わせる** → 機器の遅れで自分の線が右にずれる場合に調整
- テイクは複数保存でき、WAVでダウンロードもできます
- ショートカット：Space 再生/一時停止、R 録音、Esc 停止

## 🎹 鍵盤トレーニング

- **鍵盤をクリック**（または PC キー A W S E D …）で単音を鳴らし、同じ高さで歌います
- メーターと軌跡で「高い／低い」「何セントずれているか」がリアルタイムにわかります
- **トレーニング開始** → お手本 → あなたの番 → 判定 を自動でくり返します
  - 出題：ランダム／となりの音／跳躍／ドレミ音階／同じ音
  - 合格のずれ・キープ時間・制限時間・音域を調整できます
- 結果の表で「お手本」「自分」「続けて」を再生して聴き比べできます

## 練習のコツ

1. まずは鍵盤トレーニングで「同じ音」「となりの音」から。合格のずれは「入門」でOK
2. 結果の「傾向」を見て、低め／高めのクセを把握する
3. 音源トレーニングでは1フレーズだけ区間指定し、ガイド音ON → OFF の順で慣らす

## ファイル構成

```
index.html        画面
css/style.css     見た目
js/pitch.js       音程検出（YIN法）
js/audio.js       マイク・録音・音の再生
js/ui.js          描画の共通処理
js/song.js        音源トレーニング
js/keys.js        鍵盤トレーニング
js/app.js         全体の制御・設定の保存
server.js         ローカルサーバー（start.bat から起動）
```
